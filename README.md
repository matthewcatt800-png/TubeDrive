# TubeDrive

An Android application project.

## Overview
TubeDrive is an Android app workspace. The repository contains the application source and project configuration.

## Getting started
1. Clone the repository.
2. Open it in Android Studio.
3. Allow Gradle to sync.
4. Build and run on a compatible Android device or emulator.

If a prebuilt APK is included in the repository, check its filename and the latest project notes before installing it.

Development project. Refer to the source for the current functionality.
